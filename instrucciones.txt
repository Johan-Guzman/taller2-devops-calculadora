GUÍA RÁPIDA - CALCULADORA DISTRIBUIDA

1. PRUEBAS DE TALLER 2
Windows:
  scripts\test.bat
Linux/macOS/Git Bash:
  ./scripts/test.sh

Resultado esperado:
  OK - Todas las pruebas pasaron

2. EJECUCIÓN SIN DOCKER EN DOS EQUIPOS
Backend:
  ./scripts/run-backend.sh 8082
Frontend:
  ./scripts/run-frontend.sh http://IP_BACKEND:8082 8081

En Windows use los archivos .bat equivalentes. Si un puerto está ocupado, cambie el argumento y use el mismo valor en la URL correspondiente.

3. EJECUCIÓN CON DOCKER
  docker compose up -d --build

Puertos por defecto:
  Frontend: http://localhost:8081
  Backend:  http://localhost:8082

Puertos alternativos:
  BACKEND_PORT=8092 FRONTEND_PORT=8091 docker compose up -d --build

4. VALIDACIÓN DE ENDPOINTS
  ./scripts/test_endpoints.sh

5. TALLER 3
- Registrar un runner self-hosted Windows con etiqueta calculadora-ops.
- Configurar las variables/secrets indicadas en README.md.
- Habilitar SSH entre los PC Ops emparejados.
- Ejecutar scripts/configure-firewall.ps1 como Administrador.
- Hacer push a main: CI valida el proyecto y CD despliega desde el runner.

Endpoints:
  POST /api/sum
  POST /api/subtract
  POST /api/multiply
  POST /api/divide
  GET  /api/history
  GET  /health
  GET  /status  (Frontend)
