REQUISITOS - TALLER 2 Y TALLER 3

DESARROLLO / PRUEBAS LOCALES
- JDK 17 o superior con java y javac en PATH.
- Navegador web moderno.
- Bash para scripts .sh (Linux/macOS o Git Bash en Windows).
- curl para las pruebas de endpoints.

PC OPS - TALLER 3
- Windows con Docker Desktop y Docker Compose operativos.
- Git for Windows / Git Bash.
- Runner self-hosted de GitHub Actions registrado y encendido.
- Cliente OpenSSH (ssh y scp).
- Servidor OpenSSH habilitado si este PC recibirá el despliegue del equipo par.
- Firewall activo con los puertos explícitamente autorizados.

PUERTOS PROPUESTOS
- Aplicación propia: Frontend 8081, Backend 8082.
- Aplicación recibida del equipo par: Frontend 8083, Backend 8084.
- SSH: 22.

Los puertos son configurables. No se requiere Maven, Gradle, Node.js ni una base de datos externa.
